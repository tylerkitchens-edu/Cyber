Lesson 9: Evaluate Network Security Capabilities

CompTIA Security+ (SY0-801)

Overview

Lesson 5 was about designing the network. This lesson is about the tools that protect and watch it: firewalls, intrusion detection and prevention, network access control and filtering.

You will learn:

  • firewall types: rule-based, Layer 4 and Layer 7, unified threat management (UTM) and web application firewalls (WAF);
  • network and host intrusion detection and prevention (IDS and IPS);
  • network access control (NAC): 802.1X, captive portals and posture checks;
  • content filtering, proxies, email security (SPF, DKIM, DMARC) and network monitoring tools.

On the exam this is mostly objectives 4.1 (mitigating controls: firewalls, IDS and IPS, NAC, content filters, email security) and 4.4 (monitoring tools and protocols).

Step 3: Key ideas to remember

Firewalls

TypeWhat it looks at
Layer 4 (stateful)Addresses, ports and connection state: "allow TCP 443 to the web server"
Layer 7 (next-generation)The application itself: can tell Facebook from Salesforce even on the same port
Web application firewall (WAF)Web requests, to block attacks such as SQL injection and cross-site scripting
Unified threat management (UTM)One box combining firewall, IPS, antivirus and content filtering; common in small offices

Firewall rules are read top to bottom and the first match wins, ending in an implicit "deny everything else". Rate limiting caps how many requests a source can make, which slows brute-force and denial-of-service attacks.

IDS and IPS

  • An IDS watches and alerts (detective). An IPS sits in the traffic path and can block (preventive).
  • Network-based (NIDS/NIPS) watches traffic on a network segment; host-based (HIDS/HIPS) runs on one computer; a wireless IPS (WIPS) watches for rogue access points.
  • Signature-based detection matches known attacks; anomaly-based detection flags anything unusual compared with normal behaviour (it can catch new attacks but raises more false alarms).

Network access control (NAC)

802.1X makes a device authenticate before a switch port or Wi-Fi network lets it on. NAC can also check posture (is it patched, is antivirus running?) and put failing devices in a quarantine network. Guest Wi-Fi often uses a captive portal, the page where you accept terms or sign in.

Filtering and email security

  • Content filters and proxies block malicious or unwanted websites, centrally or with an agent on each device.
  • SPF lists the servers allowed to send a domain's email; DKIM signs each message; DMARC tells receivers what to do when SPF or DKIM fails (and sends reports). BIMI shows a verified brand logo next to authenticated mail.

Watching the network

NetFlow records who talked to whom and how much; a packet analyzer (fed by port mirroring) captures the full traffic; SNMP monitors device health; syslog carries logs to a central server.

Check your understanding

A device should block attacks in real time, not just report them. Which should be deployed?

An IPS sits in the traffic path and can drop malicious traffic. An IDS only alerts.

Which email control tells receiving servers to reject messages that fail SPF and DKIM checks for your domain?

DMARC sets the policy (none, quarantine, reject) and sends reports back to the domain owner.

Laptops must authenticate and pass a patch check before they get on the corporate network. What provides this?

NAC uses 802.1X for authentication and can check the device's posture before admitting it.
