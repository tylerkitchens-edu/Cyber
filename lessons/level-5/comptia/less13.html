Lesson 13: Analyze Indicators of Malicious Activity

CompTIA Security+ (SY0-801)

Overview

This lesson is about recognising an attack from the evidence it leaves: the type of malware, the attack technique, and the indicators in logs and on systems. It is one of the most scenario-heavy parts of the exam.

You will learn:

  • malware types: ransomware, trojans, worms, viruses, spyware, rootkits, keyloggers, logic bombs and fileless malware;
  • social engineering (phishing, smishing, vishing, whaling, quishing, deepfakes) and physical attacks;
  • network and credential attacks: DDoS, DNS attacks, on-path, password spraying, brute force, MFA bypass;
  • indicators of compromise, and the log and data sources used to investigate them.

On the exam this is mostly objectives 2.5 (indicators of malicious activity) and 4.8 (data sources for an investigation).

Step 3: Key ideas to remember

Malware

TypeTell-tale sign
RansomwareFiles encrypted, a ransom note
TrojanLooks like useful software, hides a malicious payload
WormSpreads by itself across the network, no user action needed
VirusAttaches to files and needs a user to run them
RootkitHides deep in the operating system; normal tools can't see it
Keylogger and spywareRecords keystrokes or activity and sends it out
Logic bombWaits for a trigger (a date, an employee being removed from payroll)
FilelessRuns in memory using built-in tools such as PowerShell; little on disk for antivirus to find

Social engineering and physical attacks

Phishing (email), smishing (text), vishing (voice), quishing (QR codes), spear phishing (one targeted person), whaling (executives). Deepfakes fake a real person's voice or video, for example a "CEO" on a call asking for an urgent payment. Physical attacks include tailgating, shoulder surfing, card skimming and forced entry.

Network and credential attacks

  • DDoS: floods a service from many sources. On-path (man-in-the-middle): the attacker sits between two parties. DNS cache poisoning: fake DNS answers send users to the wrong site. Protocol downgrade: forces a weaker, breakable protocol.
  • Password spraying: a few common passwords against many accounts (avoids lockouts). Brute force: many passwords against one account. MFA bypass: for example flooding a user with push prompts until they approve one.

Indicators of compromise

Known-bad file hashes, IP addresses or domains; unknown processes; impossible travel (signing in from two countries an hour apart); concurrent sessions; many account lockouts; unusual CPU, disk or network use; logs that are missing or have gaps (log manipulation); odd timestamps.

Where the evidence is

Authentication, endpoint, application, network and firewall logs; NetFlow; packet captures; vulnerability scans; dashboards; even surveillance footage. For forensics, capture a memory dump first, then a bit-level copy of the disk, and check log and file integrity with hashes.

Check your understanding

Malware spreads from computer to computer across the network with no one opening a file. What is it?

Worms self-propagate. Viruses need a user to run an infected file; trojans need a user to install them.

Logs show one failed sign-in each for 3,000 different accounts, all using "Winter2026!". What attack is this?

One common password across many accounts keeps each account under the lockout limit. Brute force targets one account with many passwords.

A user signs in from Denver, then 20 minutes later from Singapore. What indicator is this?

No one can travel that fast. The account's credentials or session were probably stolen.
