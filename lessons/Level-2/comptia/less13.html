What the exam expects

Most management tools open faster from the Run box (Win+R) than from menus. Learn each tool's job and its command; the exam asks "which tool would you use to...".

ToolCommandUse it to
Event Viewereventvwr.mscRead logs of errors, warnings and crashes (Windows Logs > System and Application).
Disk Managementdiskmgmt.mscCreate, format and resize partitions; assign drive letters.
Task Schedulertaskschd.mscRun a program or script automatically at a set time or event.
Device Managerdevmgmt.mscSee every device, update or roll back drivers, find devices with problems.
Certificate Managercertmgr.mscView and manage the user's security certificates.
Local Users and Groupslusrmgr.mscCreate accounts and add them to groups (not in Windows Home).
Performance Monitorperfmon.mscTrack CPU, memory and disk use over time.
Group Policy Editorgpedit.mscSet policies such as password rules (not in Windows Home).
Servicesservices.mscStart, stop and set the startup type of background services.
System Informationmsinfo32See hardware, BIOS/UEFI mode and Windows version in one place.
Resource MonitorresmonSee exactly which process is using the disk, network or memory.
System ConfigurationmsconfigChoose a diagnostic startup or Safe boot for troubleshooting.
Registry EditorregeditEdit Windows' settings database directly. Back it up first: one wrong change can stop Windows starting.

Task Manager (Ctrl+Shift+Esc)

  • Processes: what is running and how much CPU, memory, disk and network each uses; End task closes a frozen program.
  • Performance: live graphs for CPU, memory, disk, network and GPU.
  • Startup apps: turn off programs that launch at sign-in and slow the computer down.
  • Users and Services tabs: who is signed in and which services are running.

Check your understanding

A computer restarted by itself overnight. Where do you look first to find out why?

Event Viewer keeps the System log, which records crashes, unexpected shutdowns and the errors that came before them.

A backup script must run every night at 2 AM, even when nobody is signed in. Which tool sets that up?

Task Scheduler runs programs and scripts at set times or on events, with or without a user signed in.

A user's computer takes several minutes to become usable after they sign in. Which Task Manager tab should you check first?

The Startup apps tab lists programs that launch at sign-in and how much each slows the start. Disable the ones the user doesn't need.

Try it on your computer (Windows, 5 minutes)

  1. Press Win+R, type eventvwr.msc. Open Windows Logs > System and find one Error. What was the source, and when did it happen?
  2. Open Task Manager (Ctrl+Shift+Esc) > Startup apps. Which app has the highest startup impact?
  3. Run msinfo32. Find your BIOS Mode and Installed Physical Memory (RAM).

Look only: don't change anything in these tools on a computer you rely on.
