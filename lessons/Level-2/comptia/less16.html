What the exam expects

Before you install: check the requirements

Windows 11 needs a 64-bit processor with at least 2 cores at 1 GHz, 4 GB of RAM, 64 GB of storage, UEFI firmware with Secure Boot, and a TPM 2.0 security chip. Older computers often fail on TPM 2.0 or Secure Boot. Also check that the user's applications and hardware drivers work on the new version, and back up their data first.

How to start the installer (boot methods)

  • USB flash drive: the most common; made with Microsoft's Media Creation Tool.
  • Network (PXE boot): the computer loads the installer from a server, which is useful for many machines at once.
  • ISO file mounted in a virtual machine, an internal recovery partition, or an external drive.

Types of installation

TypeWhat it does
Clean installWipes the drive and installs fresh. Nothing is kept, so restore data and reinstall apps afterwards.
In-place upgradeInstalls the new version over the old one and keeps files, settings and apps.
Image deploymentCopies a prepared, ready-configured image to many computers.
Zero-touch / remote deploymentNew computers set themselves up from the cloud the first time a user signs in.
Repair installReinstalls Windows over itself to fix problems while keeping files and apps.

Preparing the drive

Choose the partition style (GPT for UEFI computers, MBR only for old BIOS systems), create partitions, and format them. A quick format just creates a new file system; a full format also checks the drive for bad sectors and takes much longer.

After the install

Install drivers and Windows updates, install the user's applications, restore their data, check that everything works, and record what you did.

Check your understanding

A five-year-old PC fails Microsoft's Windows 11 compatibility check even though it has 16 GB of RAM and a 512 GB SSD. What is the most likely reason?

TPM 2.0 and Secure Boot are the Windows 11 requirements older computers most often miss. Its RAM and storage are well above the minimum.

A user wants Windows 11 on their Windows 10 laptop and wants to keep all their files and apps. Which installation type fits?

An in-place upgrade keeps files, settings and apps. A clean install wipes the drive. Back up first anyway.

A school needs to install the same configured Windows setup on 60 lab computers. Which approach saves the most time?

One prepared image, deployed over the network with PXE boot, sets up every computer the same way without visiting each one with a USB drive.

Try it on your computer (Windows, 5 minutes)

  1. Press Win+R, type tpm.msc. Does your computer have a TPM, and which Specification Version (2.0?)?
  2. Run msinfo32. Find BIOS Mode (UEFI or Legacy) and Secure Boot State.
  3. Open Disk Management, right-click Disk 0 > Properties > Volumes. Is the partition style GPT or MBR?

Could your computer run Windows 11? Which requirement would you check first on an older one?
