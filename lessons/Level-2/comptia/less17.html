What the exam expects

Linux

Linux comes in many distributions (Ubuntu, Debian, Fedora, Red Hat Enterprise Linux, Linux Mint). Most use the ext4 or XFS file system. You manage it mostly from the terminal, and the exam expects you to know what each common command does.

CommandWhat it does
ls, pwd, cdList a folder's contents; show the current folder; change folder
cp, mv, rmCopy; move or rename; delete files
chmod, chownChange a file's permissions; change its owner
sudo, suRun one command as the administrator (root); switch to another user
apt, dnfInstall and update software (Debian and Ubuntu use apt; Fedora and Red Hat use dnf)
grep, findSearch inside files for text; search for files by name
ps, topList running processes; live view of processes and resource use
ip, ping, digShow and set network addresses; test a connection; look up DNS
df, duFree space on each drive; space used by a folder
nano, manEdit a text file; read the manual for any command (man ls)

Root is the Linux administrator account. Good practice is to sign in as a normal user and put sudo in front of the few commands that need admin rights.

macOS

FeatureWhat it is

System SettingsThe macOS control panel (called System Preferences before macOS 13)
KeychainStores passwords, certificates and keys

Check your understanding

On an Ubuntu server, you try to install a package and get "permission denied". What do you put in front of the install command?

sudo runs a single command with administrator (root) rights, for example sudo apt install htop. su switches you to another user for the whole session.

Which Linux command searches inside files for a word, such as "error" in a log file?

grep searches the contents of files for text. find searches for files by their name or other properties.

A Mac user wants their whole drive encrypted in case the laptop is stolen. Which macOS feature do they turn on?

FileVault encrypts the whole drive. Time Machine is backup, Keychain stores passwords, and Spotlight is search.

Try it (Linux in your browser, or a Mac, 10 minutes)

  1. No Linux computer? Open JSLinux and start one of the Linux consoles. It runs in your browser.
  2. Type pwd, then ls -l /etc. Read one line of the output: who owns the file, and what are its permissions?
  3. Try df -h and ps. If man is installed, man ls shows the manual (press q to quit).

On a Mac: open Terminal (Cmd+Space, type "Terminal") and try the same commands.
