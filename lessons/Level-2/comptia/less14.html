Common problems and first steps

SymptomLikely causesFirst steps
Blue screen (stop error) and restartA bad driver or update, failing RAM or drive, overheatingNote the stop code; check Event Viewer; undo the latest driver or update; boot to Safe Mode if needed.
Slow performanceToo many startup apps, low RAM, a full drive, malwareTask Manager (Processes, Startup apps); free disk space; scan for malware.
Program crashes or won't openA corrupted install, missing update, incompatibilityRepair or reinstall the app; check for updates; run it as administrator if it needs to be.
Service fails to startA dependency stopped, wrong account, corrupted filesCheck services.msc and Event Viewer for the reason.
Won't bootCorrupted boot files, a bad update, a failing driveWindows Recovery Environment: Startup Repair, uninstall updates, System Restore.

Recovery tools, from least to most drastic

  1. Safe Mode: starts Windows with only basic drivers and services, so you can remove the thing causing problems.
  2. Roll back a driver (Device Manager) or uninstall a recent update.
  3. sfc /scannow (System File Checker, run as administrator): finds and repairs damaged Windows system files.
  4. System Restore: returns system files, drivers, settings and installed programs to an earlier restore point. Personal files are not changed.
  5. Startup Repair in the Windows Recovery Environment (WinRE): fixes problems that stop Windows booting.
  6. Reset this PC: reinstalls Windows, with the choice to keep or remove personal files. Apps must be reinstalled.

Always try the least drastic fix first, and back up the user's data before anything that could remove it.

Check your understanding

A computer started showing blue screens right after a new graphics driver was installed. What should the technician try first?

The problem started with the new driver, so undo that change first. Safe Mode loads only basic drivers, so the computer stays up long enough to roll it back.

A user ran System Restore to fix a problem. What happens to the documents they saved yesterday?

System Restore changes system files, drivers, settings and installed programs. It leaves personal files such as documents and photos alone.

Windows reports that some of its own system files are damaged. Which command checks and repairs them?

System File Checker (sfc /scannow, run as administrator) compares Windows system files with known good copies and repairs any that are damaged.

Try it on your computer (Windows, 5 minutes)

  1. Open Settings > System > Recovery. Find Reset this PC and Advanced startup. Look only: don't click Reset.
  2. Press Win+R, type sysdm.cpl, open the System Protection tab. Is protection on for your C: drive? When was the last restore point?
  3. Open Device Manager, double-click any device, open the Driver tab and find Roll Back Driver. (It is greyed out if there is no older driver to go back to.)
