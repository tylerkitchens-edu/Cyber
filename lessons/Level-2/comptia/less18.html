Lesson 9: Configuring SOHO Network Security

Small office and home office (SOHO) networks usually depend on one router that does everything. In this lesson you learn how to lock that router down and the attacks it protects against.

What the exam expects

Securing a SOHO router

  • Change the default admin password first. Default passwords are published online.
  • Update the firmware to patch security holes.
  • Use WPA3 (or WPA2 with AES if a device can't do WPA3) and a strong passphrase. Never WEP or WPA.
  • Turn off WPS: its 8-digit PIN can be brute-forced.
  • Change the default SSID, so the name doesn't reveal the router model. Hiding the SSID adds almost no security.
  • Guest network: visitors get internet access but can't reach your computers and printers.
  • Turn off UPnP unless you need it: it lets programs on the network open ports in the firewall by themselves.
  • Turn off remote management from the internet.

Router features you need to know

FeatureWhat it does
Port forwardingSends traffic arriving on one port to one inside device (for example, port 443 to a web server)
DMZ (screened subnet)Puts one device outside the firewall's protection. Use it only when port forwarding can't work.
DHCP reservationAlways gives a device (such as a printer) the same IP address
MAC address filteringAllows only listed devices. Weak on its own: MAC addresses are easy to fake.
Content filteringBlocks websites by category or name
Static WAN IPA fixed public address from the internet provider, needed if you host a service

Attacks on wireless networks

  • Evil twin: a fake access point with the same name as a real one, to capture what users send.
  • On-path attack (once called man-in-the-middle): the attacker sits between two devices and reads or changes the traffic.
  • Denial of service (DoS): flooding or jamming so legitimate users can't connect.

Check your understanding

A home office has a printer whose IP address keeps changing, so the computers lose it. What should you set up on the router?

A DHCP reservation always gives the printer the same IP address. A DMZ would expose the printer to the internet.

Which router setting should you turn off because its PIN can be brute-forced?

Wi-Fi Protected Setup (WPS) uses an 8-digit PIN that is checked in two halves, so it can be guessed quickly.

Visitors at a small office need internet access, but must not be able to reach the office file server. What is the best option?

A guest network gives internet access but keeps guests apart from the office devices.

Try it on your computer (Windows, 5 minutes)

  1. Find your router's address: press Win+R, type cmd, then run ipconfig and look for Default Gateway.
  2. If it's your own router, open that address in a browser and sign in. Look only; don't change anything. Find the Wi-Fi security type (WPA2 or WPA3?), whether WPS is on, the firmware version and any port forwarding rules.
  3. No access to the router? Open Windows Settings > Network & internet > Wi-Fi > your network's properties and find the Security type.
