What the exam expects

Accounts, groups and User Account Control

  • Administrators can change anything; standard users can use the computer but can't install most software or change system settings. Use standard accounts for daily work (least privilege).
  • Guest access is disabled by default and should stay that way.
  • User Account Control (UAC) asks for confirmation, or an administrator's password, before a change that needs administrator rights. It stops programs from making system changes silently.
  • Sign-in options: password, PIN, Windows Hello (face or fingerprint), security key. A Windows Hello PIN works only on that one device, which makes it safer than reusing a password.

NTFS and share permissions

  • NTFS permissions (the folder's Security tab) apply to everyone, whether they sit at the computer or connect over the network: Full control, Modify, Read & execute, Read, Write.
  • Share permissions (Advanced Sharing) apply only to people connecting over the network: Full Control, Change, Read.
  • Over the network, Windows applies both, and the more restrictive one wins.
  • Permissions are inherited from the parent folder by default. A file moved within the same drive keeps its permissions; a file copied, or moved to another drive, takes the permissions of its new folder.

Encryption and built-in protection

  • BitLocker encrypts a whole drive (Pro and higher), usually with the key kept in the computer's TPM chip. BitLocker To Go encrypts removable drives.
  • EFS (Encrypting File System) encrypts individual files and folders for one user account on NTFS.
  • Microsoft Defender Antivirus and Windows Defender Firewall are on by default; check them in the Windows Security app.

Check your understanding

A shared folder gives the Sales group "Full Control" share permission, but its NTFS permission for Sales is "Read". What can a salesperson do when they open it over the network?

Over the network both sets apply, and the more restrictive one wins. NTFS Read is more restrictive than share Full Control.

An employee carries client files on a USB flash drive. How should the drive be protected if it is lost?

BitLocker To Go encrypts removable drives, so the files can't be read without the password or recovery key.

Why does Windows show a User Account Control prompt when you install a program?

UAC stops programs from making system-wide changes without someone confirming, or entering an administrator password on a standard account.

Try it on your computer (Windows, 5 minutes)

  1. Open the Windows Security app. Is Virus & threat protection on? Is the Firewall on for your current network type?
  2. Open Settings > Accounts > Your info. Is your account an administrator or a standard user? Then open Sign-in options: which methods are set up?
  3. Right-click any folder in your Documents, choose Properties > Security. Which users and groups have access, and with which permissions? Look only.
