Lesson 12: Using Data Security

CompTIA A+ Core 2

Data has to be protected for its whole life: while it's stored, while it moves, and when the drive it lives on is retired. In this lesson you learn encryption, data handling and how to destroy data properly.

What the exam expects

Protecting stored data

  • BitLocker encrypts a whole drive (Windows Pro and above); BitLocker To Go encrypts USB drives. Keep the recovery key somewhere safe.
  • Encrypting File System (EFS) encrypts single files and folders for one user account (Windows Pro and above).
  • FileVault is the macOS full-disk encryption.
  • Data loss prevention (DLP) software stops sensitive data, such as card numbers, from leaving by email or USB.

Destroying data when a drive is retired

MethodWhat it isDrive can be reused?
Standard formatRebuilds the file system; the old data can often be recovered with toolsYes, but it isn't safe for sensitive data
Erasing / wipingOverwrites every part of the drive, or uses the drive's built-in secure erase (best for SSDs)Yes
DegaussingA strong magnet scrambles a hard disk's platters; it doesn't work on SSDsNo
Shredding, drilling, crushing, incinerationPhysical destructionNo

When an outside company destroys drives, it should give you a certificate of destruction as proof.

Regulated data

Some data has legal rules: personally identifiable information (PII), health information (PHI, under HIPAA), payment card data (PCI DSS) and government data. You met these on the Cybersecurity Fundamentals page; the CompTIA lesson adds how to handle them.

Check your understanding

A company is selling old laptops with SSDs and wants the drives reused safely. Which method fits?

A secure erase overwrites all the data and leaves the drive usable. Degaussing doesn't work on SSDs, drilling destroys the drive, and a standard format leaves recoverable data.

A contractor shredded 200 hard drives for you. What document should you get from them?

The certificate of destruction proves the drives were destroyed, which matters for audits and regulations.

A user wants to encrypt one folder of personal files on a shared Windows Pro computer, not the whole drive. What should they use?

EFS encrypts individual files and folders for a user account. BitLocker encrypts the whole drive, and FileVault is for macOS.

Try it on your computer (Windows, 5 minutes)

  1. Open Settings and search for BitLocker (Windows Pro) or Device encryption (Windows Home). Is your C: drive encrypted?
  2. Right-click a test folder > Properties > Advanced. Find the "Encrypt contents to secure data" option (EFS; greyed out on Windows Home). Look only; there's no need to turn it on.

On a Mac: System Settings > Privacy & Security > FileVault.
