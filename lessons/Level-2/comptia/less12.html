What the exam expects

Two places for settings

Windows has the modern Settings app and the older Control Panel. Microsoft keeps moving things into Settings, but Control Panel is still used for several tools, and the exam expects you to know both.

TaskWhere
Install updates, pause updatesSettings > Windows Update
Uninstall or repair a programSettings > Apps > Installed apps, or Control Panel > Programs and Features
Add or change user accountsSettings > Accounts, or Control Panel > User Accounts
Wi-Fi, Ethernet, network profile, VPNSettings > Network & internet
Screen resolution, scaling, multiple monitorsSettings > System > Display
Sleep timers, lid and power button actionsSettings > System > Power, or Control Panel > Power Options
Show hidden files and file extensionsFile Explorer Options (Control Panel), or File Explorer's View menu
Proxy and browser security zonesControl Panel > Internet Options

Settings worth knowing well

  • Network profile: Public hides the computer from other devices on the network (use it on coffee-shop and hotel Wi-Fi). Private allows network discovery and file sharing (home or trusted office).
  • Sleep vs hibernate: sleep keeps your work in RAM using a little power, and wakes in seconds. Hibernate saves the contents of RAM to the drive and powers off completely. Fast startup is a partial hibernate that makes boot faster.
  • File extensions: Windows hides them by default. Turning them on lets users spot a dangerous file such as invoice.pdf.exe.
  • Accounts: a local account exists only on that computer; a Microsoft account signs in with an email address and syncs settings and OneDrive. Either can be a standard user or an administrator.

Check your understanding

A user received "invoice.pdf" by email, but your security team says it was really a program. What setting would have helped the user spot this?

With extensions shown, the file appears as invoice.pdf.exe, which gives it away as a program. Windows hides known extensions by default.

A salesperson connects their laptop to hotel Wi-Fi. Which network profile should Windows use?

Public hides the laptop from other devices on an untrusted network and turns off discovery and sharing.

A user wants their laptop to use no battery at all overnight but still reopen all their windows in the morning. What should they use?

Hibernate saves everything in RAM to the drive and powers off completely. Sleep keeps RAM powered, so it slowly uses battery.

Try it on your computer (Windows, 5 minutes)

  1. Open File Explorer, then View > Show > File name extensions. Look at a few files: what extensions do you see?
  2. Open Settings > Network & internet, click your connection and check whether it is Public or Private. Is that the right choice for where you are?
  3. Press Win+R, type control and press Enter. Find Programs and Features and Power Options, then find the same settings in the Settings app.
