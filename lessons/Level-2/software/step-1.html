Types of software

Software is the programs, data and instructions that tell a computer's hardware what to do. You will see it sorted in two ways. Both are common, and they don't disagree: the three-type version just splits one group in two.

The two-type view

  • System software runs the computer itself: the operating system, device drivers, firmware and utility programs (backup, antivirus, disk tools).
  • Application software does a job for the user: web browsers, word processors, email clients, games, and also the tools developers use to write code.

The three-type view

  • System software: the same as above.
  • Application software: programs for end users.
  • Programming software: tools for building other software, such as code editors and integrated development environments (IDEs), compilers and debuggers. In the two-type view these count as applications.

On a test: read the answer choices. If "programming software" is one of them, the question is using the three-type view. If a question asks for "the two main types", the answer is system and application.

You may also hear about middleware (software that connects other applications, such as a database connector) and enterprise software (large business systems for things like payroll or customer records). They are kinds of application software, not separate types.

Which operating system runs where

  • Desktops and laptops (workstations): Windows, macOS, Linux, or ChromeOS on Chromebooks.
  • Servers: mostly Windows Server and Linux.
  • Phones and tablets: Android and iOS/iPadOS.
  • Embedded devices (smart TVs, routers, game consoles, cars): a small, specialized operating system stored in the device's firmware, the software kept on a chip on the device. It does one job and rarely changes.
  • Hypervisors: software that runs several operating systems on one physical machine (virtualization, from the Level 1 Cloud Computing lesson).

What an operating system does

  • User interface: a graphical user interface (GUI) of windows, icons and menus, and a command-line interface (CLI) where you type commands, such as Command Prompt, PowerShell or a Linux terminal.
  • Go-between for hardware and applications: applications ask the OS to read a file or draw on screen; the OS turns that into instructions the hardware understands.
  • Process and memory management: many programs run at once, and the OS shares out CPU time and RAM between them. Task Manager shows this.
  • Device management: the OS talks to each device through a driver, a small program that translates between the OS and that piece of hardware. Device Manager shows every device and its driver.
  • Storage management: Windows' Disk Management tool (diskmgmt.msc) creates, deletes and resizes partitions, formats volumes and assigns drive letters. Separately, Windows' "Defragment and Optimize Drives" tool keeps hard drives tidy and sends TRIM to SSDs; it runs automatically.
  • File management: organizes data into folders and files. On Windows you use File Explorer.
  • Application and service management: installing and removing programs, and running services, programs that work in the background without a window (Windows Update, the print spooler, search indexing).
  • Security and access control: users sign in, and the OS decides what each account may do. The principle of least privilege means giving each account only the access it needs for its job. Everyday work happens in a standard account, and an administrator account is used only when needed. If a standard account is tricked into running malware, the damage is limited.

A new employee only needs to use email and the company's sales app. Following the principle of least privilege, what kind of account should they get?

Least privilege means only the access needed for the job. A standard account can use email and the sales app but can't install software or change system settings, which limits the damage if the account is misused.

A technician needs to give a newly installed second drive a letter so it shows up in File Explorer. Which tool do they use?

Disk Management (diskmgmt.msc) creates and formats volumes and assigns drive letters. Device Manager shows the drive's hardware and driver, but it doesn't set up volumes.

Windows editions and versions

Windows comes in editions with different features. A support technician needs to know which edition a computer has, because some tasks are impossible on Home.

EditionWho it's forKey differences
HomePersonal computersCan't join a company domain. No BitLocker drive encryption (some devices have the simpler "device encryption"). No Group Policy Editor. Can't be the host for incoming Remote Desktop connections.
ProSmall businesses and power usersAdds domain join, BitLocker, Group Policy and Remote Desktop host.
EnterpriseLarge organizations (volume licensing)Everything in Pro plus extra security and management features.
EducationSchools and universitiesClose to Enterprise, licensed for education.

32-bit vs 64-bit: a 32-bit operating system can use at most 4 GB of RAM. A 64-bit operating system can use far more, and it runs both 64-bit and most older 32-bit programs. Windows 11 comes only in 64-bit. To check, go to Settings > System > About > System type.

Video: Professor Messer, "An Overview of Windows – CompTIA A+ 220-1202 – 1.3" (free A+ course).

A small business wants its laptops encrypted with BitLocker and joined to the company domain. The laptops run Windows 11 Home. What should the technician recommend?

Home can't join a domain and doesn't include BitLocker. Pro adds both.

File systems

Before a drive can store files, it must be formatted with a file system, the method the OS uses to organize and find data on it.

File systemUsed byGood to know
NTFSWindows (the default)File permissions, encryption, very large files and drives. macOS can read it but not write to it.
FAT32Older and simple devicesWorks almost everywhere, but no single file can be larger than 4 GB.
exFATUSB flash drives and memory cardsNo 4 GB file limit, and works on Windows and macOS. The usual choice for a drive shared between them.
ext4LinuxThe common Linux default.
APFSmacOS and iOSApple's current file system, designed for SSDs.
ReFSWindows ServerBuilt for reliability on large storage systems.

Video: Professor Messer, "File Systems – CompTIA A+ 220-1202 – 1.1" (free A+ course).

A video editor needs a USB drive that works on both a Windows PC and a Mac, and some video files are 10 GB. Which file system should the drive use?

exFAT works on both Windows and macOS and has no 4 GB file limit. FAT32 can't hold a 10 GB file, a Mac can't write to NTFS, and Windows can't read APFS.

Updates and end of support

Operating systems get regular security updates (patches for newly found weaknesses) and larger feature updates. Every version also has an end-of-support date, after which it gets no more security fixes. For example, Windows 10 support ended on October 14, 2025. A computer running an unsupported OS stays open to every weakness found after that date, so part of IT support is keeping systems updated and planning upgrades before support ends.

Try it on your computer (Windows, 5 minutes)

  1. Open Settings > System > About. Find your Windows edition (Home, Pro...), version, and system type (64-bit?).
  2. Right-click the Start button and choose Disk Management. How many disks and partitions does your computer have? Which file system does the C: drive use? Look only: don't change anything here.
  3. Open Task Manager (Ctrl+Shift+Esc) and the Services tab. Find a service that is running even though you never opened it.

On a Mac: Apple menu > About This Mac shows the macOS version; Disk Utility shows your drives and their file system (APFS).
