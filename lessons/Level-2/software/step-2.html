Scripting and automation

A script is a text file of commands that a program called an interpreter runs one after another. Technicians write scripts so a repeated job is done the same way every time, faster and with fewer mistakes. You don't need to be a programmer for Core 2, but you must recognize each script type and know what scripts are used for.

What every language has

  • Variables hold values (a file name, a count). Environment variables are set by the system, such as the user's home folder (%USERPROFILE% in Windows, $HOME in Linux).
  • Conditions (if/else) choose what to do; loops repeat steps for every file, user or computer.
  • Comments explain the script to the next person and are ignored when it runs (# in PowerShell, Bash and Python; REM or :: in batch files).

What scripts are used for

  • Basic automation: restarting machines, remapping network drives, installing applications.
  • Automated backups, and gathering information or data from many computers.
  • Starting updates on a schedule.

Risks to remember

  • A script from an unknown source can bring in malware. Read it before you run it.
  • A mistake can change system settings on every computer the script touches.
  • A badly written script can use up memory or processor time and crash the browser or the system. Test on one computer first.

Remote access

ToolUse it to
Remote Desktop Protocol (RDP), port 3389Control a Windows computer's desktop over the network
Virtual Network Computing (VNC)Share and control a desktop on any operating system
Secure Shell (SSH), port 22Get an encrypted command line on a Linux computer or network device
Virtual private network (VPN)Join the office network securely from home
Remote monitoring and management (RMM)Let an IT team or managed service provider watch, patch and fix many computers from one console
Screen-sharing, video-conferencing and file transfer toolsHelp a user while they watch; send files to a remote computer

Security: never expose RDP directly to the internet; put it behind a VPN. Use multifactor authentication and strong passwords, keep remote tools updated, and remove tools you no longer use. Scammers who call pretending to be "tech support" ask victims to install a remote access tool, so a legitimate technician always confirms who they are and asks permission before connecting.

Check your understanding

A technician finds a file called map-drives.ps1 on a Windows server. What kind of script is it?

.ps1 is PowerShell. Batch files are .bat, Python is .py, and Linux shell scripts are .sh.

You need an encrypted command line on a Linux web server in another city. Which tool do you use?

SSH gives an encrypted command-line session, which is how Linux servers are usually managed. RDP and VNC share a graphical desktop.

A colleague found a script online that "cleans up" Windows and wants to run it on all 200 office computers tonight. What should happen first?

Scripts from unknown sources can contain malware or change settings by mistake. Read it, test it on one machine, and follow change management before running it everywhere.

Try it on your computer (Windows, 10 minutes)

  1. Open Notepad and type these two lines: 
    Write-Output "Computer: $env:COMPUTERNAME"
Write-Output "User: $env:USERNAME"
  2. Save it as info.ps1 in your Documents folder.
  3. Open PowerShell, then run cd ~\Documents and powershell -ExecutionPolicy Bypass -File .\info.ps1. You'll see your computer and user name, read from environment variables.
  4. Windows blocks unsigned scripts by default; that's the execution policy protecting you. Only bypass it for scripts you wrote yourself or have read.
