Overview

This lesson covers application-level vulnerability assessment techniques. Topics include static application security testing (SAST), dynamic application security testing (DAST), software composition analysis (SCA), API security testing, web application vulnerability scanning, common application vulnerabilities (OWASP Top 10), secure code review concepts, and how application assessments integrate into the secure software development lifecycle (SSDLC).
