Lesson 13: Assessing Application Vulnerabilities

CompTIA CySA+ (CS0-004)

Overview

Web applications are among the most attacked systems in any organization. This lesson covers the common application flaws and the tools used to find them.

You will learn:

  • common web application vulnerabilities and how to recognise them;
  • web application scanners and proxies: Burp Suite, ZAP and Nikto;
  • cloud and infrastructure-as-code scanning tools.

On the exam this is mostly objective 2.2 (output from vulnerability assessment tools, web application scanners) and the application indicators in 1.2.

Step 3: Key ideas to remember

Common application vulnerabilities

VulnerabilityWhat it looks like
SQL injectionInput such as ' OR 1=1-- changes the database query
Cross-site scripting (XSS)The site shows a visitor's input (such as <script>) back as code in other people's browsers
Directory traversal / local file inclusion../../etc/passwd in a URL to read files outside the web folder
Broken access controlChanging ?account=1001 to 1002 shows someone else's data
Server-side request forgery (SSRF)Tricking the server into fetching internal addresses, such as cloud metadata
Cross-site request forgery (CSRF)A malicious page makes a signed-in user's browser send a request they didn't intend

Tools

  • Burp Suite: an intercepting proxy. Proxy captures traffic, Repeater resends one edited request, Intruder sends many variations automatically, and the Scanner (paid edition) finds issues automatically.
  • ZAP (Zed Attack Proxy): a free, open-source alternative with an automated scanner.
  • Nikto: scans a web server for dangerous files, outdated software and misconfigurations.
  • Cloud and IaC: ScoutSuite and Prowler audit cloud accounts; Trivy scans container images; Checkov checks infrastructure-as-code templates before deployment.

Scanner output still needs an analyst: confirm each finding (false positives are common), rate it, and give developers clear reproduction steps.

Check your understanding

A web log shows GET /download?file=../../../../etc/passwd. What is being attempted?

The "../" sequences climb out of the web folder to read system files.

Which Burp Suite tool resends a single captured request after you edit it?

Repeater is for manual, one-at-a-time testing. Intruder automates many variations.

A login form accepts admin' OR 1=1-- as a username and signs the tester in. What is the vulnerability?

The input changed the logic of the database query. The fix is parameterized queries (Lesson 14).
