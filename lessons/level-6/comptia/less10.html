Overview

This lesson covers the tools and techniques used to identify malicious activity across network, endpoint, and cloud environments. Topics include SIEM log analysis, packet capture and analysis (Wireshark, tcpdump), endpoint detection and response (EDR) tools, network traffic analysis (Zeek, Snort), email header analysis, DNS query analysis, and sandbox detonation. You will learn to correlate data across multiple sources to build a complete picture of malicious activity.
