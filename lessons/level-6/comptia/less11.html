Overview

An analyst can't read millions of log lines by hand. This lesson covers the patterns, file formats and small scripts that turn a mountain of data into an answer, and where AI fits in.

You will learn:

  • decoding and parsing data with CyberChef;
  • regular expressions for finding patterns;
  • the file formats you'll meet (JSON, XML, YAML, EVTX);
  • short Python, PowerShell and shell scripts for log analysis, and the uses and risks of AI in security operations.

On the exam this is mostly objectives 1.3 (decoding, pattern recognition, file formats, scripting) and 1.6 (AI in security operations).

Step 3: Key ideas to remember

Decoding and patterns

  • Attackers encode commands and data (Base64, hex, URL encoding) to hide them. CyberChef chains "recipes" such as From Base64, then Decompress, then Extract URLs.
  • Regular expressions describe patterns. For example \b\d{1,3}(\.\d{1,3}){3}\b finds things shaped like IPv4 addresses, and [A-Za-z0-9+/]{40,}={0,2} finds long Base64-looking strings.

File formats

FormatWhere you see it
JSONCloud logs, APIs, most modern tools
XMLOlder applications, Windows event data inside the log
YAMLConfiguration files, Sigma detection rules, infrastructure as code
EVTXSaved Windows event log files

Small scripts, big savings

Count failed SSH sign-ins by source address on Linux:

grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -nr

Count failed Windows sign-ins (event 4625) in PowerShell:

(Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625}).Count

Python does the same at larger scale (reading JSON logs, calling threat-intelligence APIs). For the exam, you should be able to read a short script and say what it does.

AI in security operations

  • Useful for: comparing artifacts, summarising long logs, drafting reports, correlating events, and helping an investigation along.
  • Risks: hallucinations (confident wrong answers, so verify), data exposure (sensitive logs pasted into a public tool), model poisoning, and malicious prompts hidden in the data being analysed.
  • Governance: follow the organization's AI usage policy and legal or regulatory rules about where data may go.

Check your understanding

A PowerShell command line contains a long string ending in ==. Which tool helps you read it quickly?

Trailing "=" signs are typical padding of Base64. Decode it in CyberChef (encoded PowerShell is often UTF-16LE).

What is an .evtx file?

EVTX is the Windows Event Log format; tools such as Event Viewer, PowerShell and SIEM agents read it.

An analyst pastes customer logs into a public AI chatbot to summarise them. What is the main risk?

Sensitive data may be stored or used by the provider. Use approved tools under the organization's AI usage policy. Also check any summary, because AI can hallucinate.
