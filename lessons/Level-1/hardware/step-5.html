The Boot Process, BIOS and UEFI

Lesson

Learning Objectives

  • Explain what firmware is, and compare BIOS and UEFI.
  • Describe each stage of the boot process, from pressing the power button to the sign-in screen.
  • Open the firmware settings and identify the settings the A+ exam covers: boot order, Secure Boot, TPM, passwords and virtualization.
  • Recognize common boot problems and their likely causes.

1. Firmware: BIOS and UEFI

Firmware is software stored on a chip on the motherboard. It is the first code that runs when the computer turns on. Its jobs are to check and start the hardware, then hand control to the operating system. There are two kinds:

BIOS (legacy)UEFI (modern)
AgeThe original PC firmware, from the 1980s.The replacement, standard on computers built in the last decade or so.
Boot disksBoots from MBR disks (up to 2 TB, 4 primary partitions).Boots from GPT disks (huge disks, up to 128 partitions in Windows), using a small EFI system partition.
SecurityNo built-in protection for the boot process.Secure Boot refuses to start boot software that is not signed by a trusted maker, which blocks many rootkits.
Setup screenText only, keyboard only.Graphical, and usually supports the mouse.
Windows 11Not supported.Required, with Secure Boot capability and TPM 2.0.

Many people still say "BIOS" when they mean UEFI, and many UEFI systems can switch to a "Legacy" or "CSM" mode that behaves like BIOS.

Where are the settings kept, and what is the CMOS battery for? Firmware settings (boot order, passwords, and so on) are saved on the motherboard. On older computers they were kept in a small memory chip called CMOS, which needed a coin battery (usually a CR2032) to keep them. Modern boards keep settings in flash memory, but the battery still runs the real-time clock. Either way, the classic sign of a dead CMOS battery is the date and time resetting every time the computer is unplugged, sometimes with lost settings or a "CMOS checksum" message.

Updating firmware ("flashing the BIOS") fixes bugs, adds support for new CPUs and closes security holes. Use only the motherboard or PC maker's update, and never let the power go off during the update: an interrupted update can leave the board unable to start.

Every time a user unplugs their desktop overnight, the date and time are wrong the next morning. What is the most likely cause?

The coin battery keeps the clock running when the computer has no power. When it dies, the clock resets every time power is removed. Replace the battery (usually a CR2032), then set the date, time and any lost settings.

2. The Boot Process, Stage by Stage

Click through each stage. For every stage you will see what happens, and what you would notice if it went wrong. Knowing where a boot stops tells you where to look.

You press the power button. The power supply starts and, once its voltages are steady, sends a "power good" signal to the motherboard. The CPU then starts running the firmware.

If it fails: nothing happens at all, or fans spin for a moment and stop. Check the outlet and power cable, the power supply switch, the 24-pin and CPU power cables, and the front-panel power button connection.

The firmware (UEFI or BIOS) loads its saved settings, such as the boot order and passwords, and begins setting up the CPU, memory and chipset.

If it fails: the computer powers on but shows nothing, or the date and settings are wrong (dead CMOS battery). A failed firmware update can also stop the board here.

The Power-On Self-Test checks the essential hardware: CPU, memory, video and keyboard controller. If everything passes, many computers give a single short beep or show the maker's logo.

If it fails: a pattern of beep codes or an error message, often with a black screen. Look the pattern up in the motherboard manual. Reseating RAM or the graphics card is a common fix.

The firmware checks the devices in the boot order (for example: USB drive, then the internal SSD, then the network) and picks the first one that has a working boot loader.

If it fails: "No boot device found", "Operating system not found" or "Insert boot media". Often a USB stick was left in and is first in the boot order, or the boot drive has failed or is not detected.

A small program called the boot loader starts the operating system. On UEFI systems it lives in the EFI system partition (for Windows, the Windows Boot Manager); on BIOS systems it starts from the disk's Master Boot Record. With Secure Boot on, the firmware checks the boot loader's signature first.

If it fails: "BOOTMGR is missing", a Secure Boot violation message, or a BitLocker recovery-key screen after a firmware or TPM change.

The boot loader loads the operating system's core (the kernel) into RAM. The kernel starts the drivers and background services, then shows the sign-in screen.

If it fails: the logo appears and then the system crashes (a blue screen), restarts in a loop, or starts Automatic Repair. A recently added driver, update or failing drive is a common cause.

A computer shows the maker's logo, then says "No boot device found". A user mentions they used a USB stick to copy files earlier. What should you check first?

POST passed (the logo appeared), so the problem is at the "find a boot device" stage. A USB stick that comes first in the boot order but has nothing bootable on it is a classic cause. Start with the simplest, most likely cause.

3. Getting Into the Firmware Settings

  • During startup: press the setup key as soon as the computer turns on. Common keys are Del, F2, F1 or F10; the startup screen or the maker's manual tells you which. A separate key (often F12) opens a one-time boot menu to boot from a USB drive without changing the boot order.
  • From Windows: on fast computers the startup screen flashes by too quickly. Go to Settings > System > Recovery > Advanced startup > Restart now, then Troubleshoot > Advanced options > UEFI Firmware Settings.

4. Firmware Settings You Need to Know

  • Boot order (boot priority): which devices the computer tries to boot from, in order.
  • Secure Boot: only allows signed, trusted boot loaders. Keep it on; Windows 11 expects it.
  • TPM (Trusted Platform Module): a security chip, or a feature built into the CPU (called fTPM on AMD and PTT on Intel), that stores encryption keys. BitLocker drive encryption and Windows 11 use it. Clearing or changing the TPM can trigger a BitLocker recovery-key prompt, so have the key before you touch it.
  • Passwords: a supervisor/administrator password stops people changing firmware settings; a user/boot password is needed before the computer will start at all.
  • Virtualization (Intel VT-x, AMD-V or SVM): must be on to run virtual machines (Hyper-V, VirtualBox, VMware) and some Windows security features.
  • Enabling and disabling devices and ports: for example, turning off USB ports so data cannot be copied off a sensitive computer, or turning off the onboard graphics when a graphics card is installed.
  • Fan and temperature settings: fan speed curves and temperature alarms.

A student installs VirtualBox, but every virtual machine fails to start with an error about hardware virtualization. What should you change?

Virtual machines need the CPU's virtualization feature, which is often turned off by default in the firmware. Turning off Secure Boot or clearing the TPM would not help, and both can cause other problems.

A company wants to stop staff from changing the boot order to start the computer from their own USB drive. What should the technician set?

A supervisor password locks the firmware settings, so the boot order cannot be changed. Many organizations also disable booting from USB. A Windows password does nothing before Windows starts.

Try it on your computer (Windows, 3 minutes)

  1. Press Windows+R, type msinfo32 and press Enter. Find BIOS Mode (UEFI or Legacy) and Secure Boot State (On or Off).
  2. Right-click the Start button and choose Disk Management. On Disk 0, find the small EFI System Partition (usually 100 to 300 MB). That is where the boot loader lives.
  3. Press Windows+R, type tpm.msc and press Enter. Is a TPM present, and which version is it?

Only look; don't change any settings, and don't open the firmware settings from Windows unless an instructor asks you to. On a Mac, Apple's own startup system is different, so this part is Windows only.
