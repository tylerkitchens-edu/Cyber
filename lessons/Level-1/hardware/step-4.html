Storage types

Lesson

Learning Objectives

  • Explain the difference between memory (RAM) and storage.
  • Compare Hard Disk Drives (HDDs) and Solid-State Drives (SSDs) in technology, speed, durability and cost.
  • Identify storage interfaces: SATA, NVMe/M.2, SAS, and the legacy PATA/IDE and SCSI.
  • Identify flash, optical, external and network-attached storage (NAS).
  • Describe RAID levels 0, 1, 5, 6 and 10.
  • Explain drives, volumes and partitions (MBR and GPT).

Memory vs. Storage

A processor uses random access memory (RAM) to hold the program it is running right now. RAM is extremely fast, but it is volatile: when the power goes off, everything in it is lost. Storage (also called mass storage) is non-volatile: it keeps your files, programs and operating system when the computer is off. Storage is much bigger and cheaper per gigabyte than RAM, but slower.

A customer needs 20 TB to store years of security-camera footage as cheaply as possible. Speed is not important. What should you recommend?

HDDs are the cheapest per gigabyte and come in the biggest sizes, which is exactly what bulk storage needs. SSDs are faster but cost more per gigabyte.

Storage Interfaces

The interface is how a drive connects to the motherboard and talks to the computer.

  • SATA (Serial ATA): the long-time standard for HDDs and 2.5-inch SSDs. Up to 6 Gb/s (about 600 MB/s). Uses a 7-pin data cable and a 15-pin power connector, and supports hot-swapping (replacing a drive while the computer is on) where the system allows it. Most motherboards have several SATA ports.
  • NVMe over PCIe (usually in an M.2 slot): today's standard for fast SSDs. NVMe drives use PCIe lanes directly, so they are many times faster than SATA. Note: M.2 is a shape, not a speed. An M.2 card can be a fast NVMe drive or a slower SATA drive, so check which kinds the slot supports.
  • SAS (Serial Attached SCSI): used in servers. Fast and reliable; a SAS controller can also run SATA drives.
  • PATA / IDE / EIDE (legacy): the older parallel interface, with a wide 40-pin ribbon cable and "master/slave" jumpers. Replaced by SATA.
  • Parallel SCSI (legacy): one of the earliest disk interfaces, developed in the late 1970s, with a 50-pin (later 68-pin) ribbon cable. Replaced by SAS.

A typical desktop today has an NVMe SSD for the operating system and programs, and may add a large SATA HDD for files and backups.

A user installs a new M.2 SSD but it is no faster than their old 2.5-inch SATA SSD. What is the most likely reason?

M.2 is only a shape. An M.2 drive can use the SATA interface (about 550 MB/s) or NVMe over PCIe (thousands of MB/s). Check both the drive and what the slot supports.

Flash, Optical, External and Network Storage

  • Flash storage: SSDs, USB flash drives (thumb drives) and memory cards (SD, microSD) all store data on flash memory. Thumb drives and memory cards are small and removable; SSDs are built for speed and installed inside the computer.
  • Optical discs: a laser reads (and can write) the data. CD: about 700 MB. DVD: 4.7 GB (8.5 GB dual layer). Blu-ray: 25 GB (50 GB dual layer). "-ROM" discs are read-only, "-R" can be written once, "-RW" can be rewritten. Mostly legacy today.
  • External drives: an HDD or SSD in an enclosure, connected by USB or Thunderbolt. Common for backups and moving large files.
  • Network-attached storage (NAS): a storage device on the network that shares files with many users, usually with several drives in RAID. (A storage area network, SAN, gives servers block-level storage over a dedicated network.)

RAID (Redundant Array of Independent Disks)

RAID combines several drives so they act as one, for speed, for protection against a drive failing, or both.

  • RAID 0 (striping): data split across 2 or more drives. Fastest, but no protection: if one drive fails, all the data is lost.
  • RAID 1 (mirroring): 2 drives hold identical copies. Survives one drive failing; you get the capacity of one drive.
  • RAID 5 (striping with parity): 3 or more drives. Survives one drive failing; one drive's worth of space goes to parity.
  • RAID 6 (double parity): 4 or more drives. Survives two drives failing.
  • RAID 10 (1+0, mirrored stripes): 4 or more drives. Fast, and survives a drive failing in each mirrored pair.

Try the simulator: fail one drive, then two, at each level, and watch what happens to the data and the usable space.

RAID is not a backup. It protects against a drive failing, not against deleted files, ransomware or a fire, so you still need backups.

Video: Professor Messer, "RAID – CompTIA A+ 220-1201 – 3.4" (free A+ course).

A small office wants its file server to keep running if any two drives fail at the same time. Which RAID level should it use?

RAID 6 stores two sets of parity, so any two drives can fail without losing data. RAID 5 survives only one, and RAID 0 survives none.

Drives, Volumes and Drive Letters

A physical disk can be divided into one or more partitions. A partition that has been formatted with a file system (such as NTFS) is a volume, and Windows gives each volume a drive letter. The volume holding Windows is usually C:.

What happened to the A and B drives? On early PCs, A: and B: were reserved for floppy disk drives (3.5-inch and 5.25-inch floppies). Floppies are gone, but hard drives still start at C: by tradition.

Partitioning

Before a new disk can be used, it gets a partition style:

  • MBR (Master Boot Record): the older style. Disks up to 2 TB and up to 4 primary partitions.
  • GPT (GUID Partition Table): the modern style, required for UEFI booting. Supports enormous disks and up to 128 partitions in Windows.

Reasons to create more than one partition:

  • Dual boot two operating systems, such as Windows and Linux.
  • Keep data separate from the operating system, so reinstalling the operating system does not erase it.
  • Hold a recovery image of the operating system (many computers ship with a hidden recovery partition).

Each file system uses a little space for its own bookkeeping, but dividing a disk into partitions does not cost a meaningful share of its capacity.

Try it on your computer (Windows, 2 minutes)

  1. Press Ctrl+Shift+Esc to open Task Manager, select Performance, then click your disk. The top right shows whether it is an SSD or an HDD.
  2. Right-click the Start button and choose Disk Management. Look at the partitions on Disk 0: which one is C:, and is there a hidden recovery partition?
  3. Right-click Disk 0 (the label on the left), choose Properties, then the Volumes tab. "Partition style" tells you whether the disk is MBR or GPT.

Only look; don't change anything in Disk Management. On a Mac, open System Information and select Storage to see your drive type.
