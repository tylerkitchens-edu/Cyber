Lesson: What's the Internet?

Level 1 - Networking

Lesson Overview

The Internet is a worldwide network of networks. Nearly every attack, defense and monitoring tool in cybersecurity depends on how data moves across it, so this lesson covers how you get online, the hardware involved, how devices are addressed, and the OSI model that people use to describe and troubleshoot networks.

Learning Objectives

  • Describe the Internet, where it came from, and the main ways homes and businesses connect to it.
  • Explain what a modem, router, switch, network card and wireless access point each do.
  • Explain MAC and IP addresses, public and private IPv4 ranges, and what DHCP, DNS and the default gateway do.
  • Compare TCP and UDP, and recognize the most common port numbers.
  • Name the seven layers of the OSI model in order and place common devices and protocols on them.

What is the Internet?

Video: Code.org, "What is the Internet?" (How the Internet Works series).

The Internet is a global network of interconnected networks that lets people share information, communicate and use online services. It began in the 1960s as ARPANET, a US Department of Defense research project that connected a few universities and introduced packet switching: breaking data into small packets that travel separately and are put back together at the destination.

Devices on the Internet communicate using the TCP/IP family of protocols, which lets data cross many networks owned by different companies. No single organization owns the Internet; it runs on agreed standards and cooperation between providers, which is also why privacy and security are constant challenges.

Ways to Connect

You reach the Internet through an Internet Service Provider (ISP), which is your on-ramp to everyone else's networks. Common connection types:

  • DSL: uses telephone lines. It replaced dial-up and lets you use the phone and the Internet at the same time. Speed drops with distance from the provider's equipment.
  • Cable: uses the coaxial TV cable. Faster than DSL and very common in homes.
  • Fibre: sends data as light through glass strands. The fastest and most reliable, and not affected by electrical interference.
  • Satellite: works almost anywhere. Traditional satellites are far away, so delay (latency) is high; low-orbit services such as Starlink reduce it.
  • Cellular: 4G and 5G mobile networks, also used for home Internet and phone hotspots.
  • Fixed wireless: a radio link from an antenna on the building to a provider's tower, common in rural areas.

Important Internet Hardware

  • Modem: connects your network to the ISP's line by turning your data into the signal that line carries (a DSL or cable signal). Fibre uses an ONT (optical network terminal) instead.
  • Router: moves packets between networks, for example between your home network and the Internet, and lets many devices share one Internet connection.
  • Switch: connects devices within one LAN and sends each frame only to the device it is meant for, using MAC addresses.
  • Network interface card (NIC): the wired or wireless adapter that connects a device to a network. Every NIC has a MAC address.
  • Wireless access point (WAP): lets wireless devices join a wired network.
  • Home (SOHO) router: one box that combines a router, a switch, a wireless access point and a firewall, and sometimes the modem too.

Inside the office, every device has its own cable to the switch (a star). The router connects that LAN to the modem and, through it, to the Internet.

Which device decides how to send a packet from your home network out to a server on the Internet?

Routers move packets between different networks. Switches only deliver frames within one LAN.

Network Addressing

Every device needs an address so data reaches the right place, the way a house needs a mailing address. There are two kinds:

  • MAC address (physical): burned into each network card by the maker, written in hex, for example 00-09-5B-36-C2-93. Used to deliver data within the local network.
  • IP address (logical): assigned by software and can change. Used to route data between networks.

IPv4 and IPv6

IPv4 addresses are 32 bits, written as four numbers from 0 to 255 (for example 192.168.1.20). That allows about 4.3 billion addresses, which ran out. IPv6 addresses are 128 bits, written in hex (for example 2001:db8::7334), with enough addresses for every device imaginable.

The services that make addressing work

  • DHCP hands out IP settings automatically: an address, the subnet mask, the default gateway and DNS servers. Addresses from DHCP are dynamic; addresses typed in by hand are static (used for servers and printers that must not move).
  • Subnet mask (for example 255.255.255.0) tells a device which addresses are on its own network and which are elsewhere.
  • Default gateway is the router's address: where a device sends anything meant for another network.
  • DNS turns names into IP addresses, so www.example.com becomes an address your computer can reach. If names stop working but IP addresses still do, suspect DNS.

A user says "the Internet is down". Their PC shows the IP address 169.254.37.12. What is the most likely cause?

169.254.x.x is a self-assigned (APIPA) address. The PC asked for an address and got no answer, so start with the cable, the Wi-Fi connection or the router.

TCP, UDP and Ports

Two protocols carry most traffic:

  • TCP is connection-oriented and reliable: it numbers packets, confirms they arrived, and resends lost ones. Used for web pages, email and file transfers. Every TCP connection starts with a three-way handshake:
    Client → Server: SYN (let's talk)
    Server → Client: SYN-ACK (OK, let's talk)
    Client → Server: ACK (connected)
  • UDP is connectionless: it just sends, with no confirmation. Faster, and fine when a lost packet doesn't matter much: video calls, streaming, online games, DNS lookups.

A video call can drop the odd packet without anyone noticing, but it must not lag. Which protocol suits it best?

UDP skips confirmations and resends, so it is faster. Resending a late video frame would only add lag.

The OSI Model

The OSI (Open Systems Interconnection) model splits network communication into seven layers. Real networks use the simpler TCP/IP model, but everyone uses OSI layer numbers to describe where a device works or where a problem is ("that's a Layer 1 problem" means a cable or signal issue).

LayerNameWhat it doesExamples
7ApplicationThe services programs useHTTP, HTTPS, DNS, SMTP, FTP
6PresentationFormatting, encryption and compressionTLS encryption, JPEG
5SessionStarting, keeping and ending conversationsSession setup for remote calls
4TransportSplitting data into segments; reliable (TCP) or fast (UDP) delivery; port numbersTCP, UDP
3NetworkIP addresses and routing between networksIP, ICMP (ping), routers
2Data LinkMAC addresses and delivery within one networkEthernet, Wi-Fi frames, switches
1PhysicalThe signal itself: cables, connectors, radio, lightCables, fibre, hubs, radio

A common way to remember the order from Layer 1 up: Please Do Not Throw Sausage Pizza Away.

A switch forwards data using MAC addresses; a router forwards it using IP addresses. Which layers do they work at?

MAC addresses belong to Layer 2 (Data Link); IP addresses and routing belong to Layer 3 (Network).

In security, the layer tells you where an attack lands and where to defend: a flood of traffic can hit Layers 3 and 4, while a website attack such as SQL injection targets Layer 7.

Try it on your computer (Windows, 5 minutes)

  1. Open Command Prompt and run ipconfig /all. For your active adapter, find the Physical Address (MAC), IPv4 Address, Subnet Mask, Default Gateway, DHCP Enabled and DNS Servers. Is your IPv4 address private? Which range?
  2. Run ping followed by your default gateway's address (for example ping 192.168.1.1). Replies mean your PC can reach the router.
  3. Run nslookup www.example.com to watch DNS turn a name into an IP address.
  4. Optional: run tracert www.example.com to see each router your packets pass through on the way.
